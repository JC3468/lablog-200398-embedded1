# Digital Inputs

## Session 6 — Two-Button Logic Gates and a Shifting LED

**Goal (one sentence):** Read two push-buttons wired with internal pull-ups as digital inputs, use them to reproduce OR, AND and XOR logic on a single LED bus, and then use the same two buttons to shift one lit LED back and forth across four positions with wrap-around.

---

### Setup

- Pin map: GP10 → PIN_D, GP11 → PIN_C, GP12 → PIN_B, GP13 → PIN_A (same 4-LED bus as Session 4); GP16 → PIN_BA (button A), GP17 → PIN_BB (button B), both configured as inputs with `gpio_pull_up()`.
- `PIN_BC` (GP18) and `PIN_BD` (GP19) are also wired on the breadboard, but the code never reads them (no `if` checks either one) — they were meant for a third exercise that we didn't get to.
- Non-default: buttons use the RP2350's internal pull-ups (no external resistor), so a press reads as a **0** (low), not a 1 — every button test in the code has to check for that low level.

### What I did

1. Reused the 4-LED bus from Session 4 (GP10–GP13) and added two push-buttons on GP16 and GP17, each set as input with `gpio_pull_up()`.
2. Wrote three versions of the same program — identical setup, only the `if` condition on the two button states changes — to make the LED bus behave like an OR, an AND, and an XOR gate.
3. Wrote a fourth program that uses the same two buttons to move a single lit LED across the four positions, one step per press, wrapping around at both ends.
4. Recorded each behavior on video as evidence.

**Shared setup code** (identical in all four programs — only the loop body changes):

```c
#define PIN_A 13
#define PIN_B 12
#define PIN_C 11
#define PIN_D 10

#define PIN_BA 16
#define PIN_BB 17
#define PIN_BC 18
#define PIN_BD 19

gpio_init(PIN_A);
gpio_init(PIN_B);
gpio_init(PIN_C);
gpio_init(PIN_D);

gpio_init(PIN_BA);
gpio_init(PIN_BB);
gpio_init(PIN_BC);
gpio_init(PIN_BD);

gpio_pull_up(PIN_BA);
gpio_pull_up(PIN_BB);
gpio_pull_up(PIN_BC);
gpio_pull_up(PIN_BD);

const uint32_t MASK =
    (1u << PIN_A) | (1u << PIN_B) | (1u << PIN_C) | (1u << PIN_D);
const uint32_t MASKB =
    (1u << PIN_BA) | (1u << PIN_BB) | (1u << PIN_BC) | (1u << PIN_BD);

// OE = Output Enable
sio_hw->gpio_oe_set = MASK;
sio_hw->gpio_oe_clr = MASKB;
```

### Exercise 1 — OR gate

LED bus on if button A **or** button B is pressed (pull-up, so "pressed" means the bit reads 0 — hence the `!`).

```c
while (true) {
    if (!(sio_hw->gpio_in & (1u<<PIN_BA)) || !(sio_hw->gpio_in & (1u<<PIN_BB))) {
        sio_hw->gpio_set = MASK;
    } else {
        sio_hw->gpio_clr = MASK;
    }
    sleep_ms(1);
}
```

### Exercise 3 — XOR gate

LED bus on when **exactly one** of the two buttons is pressed; off if neither, and off again if both.

```c
while (true) {
    if (!(sio_hw->gpio_in & (1u<<PIN_BA)) && (sio_hw->gpio_in & (1u<<PIN_BB))) {
        sio_hw->gpio_set = MASK;
    } else if (!(sio_hw->gpio_in & (1u<<PIN_BB)) && (sio_hw->gpio_in & (1u<<PIN_BA))) {
        sio_hw->gpio_set = MASK;
    } else {
        sio_hw->gpio_clr = MASK;
    }
    sleep_ms(1);
}
```

### Exercise 4 — Shift the lit LED left/right

One button advances a `counter` (0–3) and the other decreases it; only the LED at position `counter` is lit; a `flag` makes each button press count once instead of repeating every 1 ms while held; the counter wraps at both edges of the 4-LED bus.

```c
int counter = 0;
int flag = 0;

while (true) {
    sio_hw->gpio_set = (1u << (counter + 10));

    if (!(sio_hw->gpio_in & (1u<<PIN_BA)) && (flag == 0)) {
        counter++;
        flag = 1;
        sio_hw->gpio_clr = MASK;
    }
    else if (!(sio_hw->gpio_in & (1u<<PIN_BB)) && (flag == 0)) {
        counter--;
        flag = 1;
        sio_hw->gpio_clr = MASK;
    }
    else if (!(sio_hw->gpio_in & (1u<<PIN_BB))) {
        // button B still held, already handled — wait for release
    }
    else if (!(sio_hw->gpio_in & (1u<<PIN_BA))) {
        // button A still held, already handled — wait for release
    }
    else {
        flag = 0;   // neither button pressed → re-arm for the next press
    }

    if (counter > 3) {
        counter = 0;
    } else if (counter < 0) {
        counter = 3;
    }
    sleep_ms(1);
}
```
